# Vocab Venture

A browser game: explore Street View, box objects to learn their name in English, Spanish or Japanese, and earn points for each word learned.

- **Play locally:** serve this folder (`python3 -m http.server`) and open `index.html`. No build step.
- **itch.io:** run `npm run build:itch` to create `dist/vocab-venture-itch.zip` (client files only, `index.html` at the root; no server, tests or secrets). Upload it as an HTML5 game, tick "This file will be played in the browser", enable mobile-friendly/fullscreen, and set the viewport to about 960x640. Restrict your Google API key to your itch.io game's domain (`*.itch.zone`) in Cloud Console.
- **JWT secret:** only the optional backend needs it. Set `JWT_SECRET` in the server's environment (see `.env.example`); never commit it or put it in client files.
- **Controls:** Navigate with the standard Google Street View controls (click the road arrows or the ground, arrow keys, on-screen pan/zoom controls); click anywhere on the ground to walk there (even without link arrows), arrow keys also move, and scroll out gradually: Street View zooms out, then an overhead view of your street, then city, province, country and the world (or press G / the 🌍 button); scroll back in to drop into Street View. In the world view where you click anywhere to drop into Street View, TAB or the ⚙ icon opens the pause menu, drag to look around, and **right-click and drag** a box around anything in Street View to identify it (touch/trackpad: toggle the 🔍 button, then drag).
- **Learning:** each word needs 3 steps (recognize, spell, use in a sentence), then it awards 100 points. The language dropdown on the learning screen switches languages.
- **Object identification:** the box you draw in Street View crops that part of the view (Street View Static API), identifies it with Cloud Vision, translates the name with Cloud Translation, and uses it as the learning word. Learned spots show as badges. Enable the **Maps JavaScript API, Street View Static API, Cloud Vision API and Cloud Translation API** for your key. Japanese words from translation have no romaji, so spelling asks you to type the shown word.
- **Single-player rounds:** accounts and the leaderboard are on hold (hidden; set `enableAccounts: true` in `config.js` to bring them back). Pick a time limit (1-15 min) on the *Language to Learn* screen. The clock starts once Street View has loaded and pauses in the pause menu. When it ends, a game-over screen shows your score with PLAY AGAIN / QUIT. Boxing an object first asks you to name it in the language you are learning: a correct answer earns +50 bonus points, a wrong one gives 3 attempts in total (with a hint after the first), then the answer is shown; **REVEAL** skips straight to the answer. In the sentence exercise you write your own sentence using the word: it must contain the word and at least 3 words, and longer, more varied sentences earn up to 100 points. Progress and settings are kept in `localStorage`.
- **Learning flow:** the first screen shows the object's name in the language you are learning (Japanese shows hiragana for kanji, plus romaji) and in your native language (set it in Settings or on the *Language to Learn* screen). **Learn** starts recognize / spell / sentence, which hide the learned-language word. **Misidentified** reports the mistake (sent to `POST /api/misidentified` on the backend, or kept in `localStorage` offline), ranks that label lower on this device and tries the next best guess or lets you type the right name. Google's Vision API can't be retrained from the client, so reports are stored for you to review.
- **Text on objects:** signs/logos are read with Cloud Vision, translated, and each word is clickable for its translation, meaning, part of speech and how it's used (Cloud Natural Language syntax analysis; English meanings also try dictionaryapi.dev). Enable the **Cloud Natural Language API** too. Kanji readings use kuroshiro/kuromoji loaded from the jsDelivr CDN on first use.
- **Street View:** put a Google Maps API key in `config.js` (`googleMapsApiKey`). Without a key an offline pseudo-street scene is used.
- **Backend (`server/server.js`, Node 18+, no dependencies):** `node server/server.js` serves the game and an API for email/password accounts, Google/Apple/Amazon sign-in, progress + settings sync, and a global leaderboard (stored in `server/data.json`). Score is computed server-side from learned words.
  - Env vars: `JWT_SECRET` (required in production), `PORT`, `DATA_FILE`, `CORS_ORIGIN`, `GOOGLE_CLIENT_ID`, `APPLE_CLIENT_ID`, `AMAZON_CLIENT_ID` (a provider is enabled only when its ID is set; tokens are verified server-side).
  - In `config.js` set the same public client IDs (`googleClientId`, `appleClientId`, `appleRedirectUri`, `amazonClientId`). For itch.io hosting, set `apiUrl` to the deployed backend URL and `CORS_ORIGIN` to your game's origin. Set `apiUrl: null` for a fully offline mode (on-device accounts and leaderboard).
  - Endpoints: `POST /api/register|login|oauth`, `GET|PUT|DELETE /api/me`, `DELETE /api/me/progress`, `GET /api/leaderboard`.
  - You must create the Google/Apple/Amazon developer apps and deploy the backend yourself.
- **Tests:** `node test/words.test.js && node test/geo.test.js && node test/server.test.js`
